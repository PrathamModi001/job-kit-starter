Job Description

Meet the Team 
 

Join Cisco’s Customer Experience (CX) team as we build the Cisco IQ Configuration module, a new customer-facing application that helps network operators make safe, deterministic day-2 changes across devices already discovered by Cisco IQ. Our team is developing an API-first, cloud-native application that combines Python services, an Angular user interface, Cisco IQ platform capabilities, and network device orchestration. As a new grad, you’ll be mentored by experienced engineers while making meaningful contributions from day one.

Your Impact 
 

As a Software Engineer on the Cisco IQ Configuration team, you will help build a new module from proof of concept through production delivery for SaaS and on-premises environments. You’ll work alongside experienced engineers on full-stack application development, API design, platform integration, and reliable multi-device change orchestration—all while directly improving how customers operate and protect their networks.

Develop Python services and API-first capabilities for configuration workflows, command previews, approvals, scheduling, execution, and change history.

Build and integrate an Angular user experience for selecting devices, supplying workflow inputs, previewing changes, and reviewing execution results.

Integrate with Cisco IQ platform services for device inventory, validation, identity and access control, messaging, storage, observability, and device connectivity.

Help implement safe multi-device orchestration, including batching, concurrency controls, per-device reporting, partial-failure handling, and rollback.

Write clean, well-tested code; participate in code reviews; and collaborate across the full software development lifecycle from design through deployment and support.

Minimum Qualifications

Bachelor’s degree in Computer Science, Information Technology, Engineering, or a related technical field (or equivalent experience).

Programming experience in Python through coursework, internships, or personal projects.

Foundational knowledge of software engineering principles, including data structures, algorithms, object-oriented design, and testing.

Exposure to web application development, RESTful APIs, and structured data formats such as JSON or YAML.

Familiarity with Git and collaborative development practices, with an eagerness to learn from feedback.

Preferred Qualifications

Project or internship experience with Python web frameworks such as FastAPI, API contracts such as OpenAPI, or data validation libraries such as Pydantic.

Experience with Angular, TypeScript, or another modern component-based front-end framework, along with foundational HTML and CSS skills.

Exposure to cloud-native development and deployment technologies such as Docker, Kubernetes, or CI/CD pipelines.

Familiarity with networking fundamentals, network automation, or Cisco device platforms such as IOS XE, IOS XR, or NX-OS.

Interest in distributed systems, workflow orchestration, secure application development, and building reliable customer-facing software in a collaborative team environment.
